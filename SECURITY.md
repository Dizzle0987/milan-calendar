# Sicurezza

## Versioni supportate

È supportata esclusivamente la versione presente sul branch `main`.

## Segnalare una vulnerabilità

Non aprire una issue pubblica per problemi di sicurezza. Usa **Security → Report a vulnerability** nel repository GitHub e includi:

- descrizione e impatto;
- passaggi per riprodurre il problema;
- eventuale soluzione suggerita.

Non inviare credenziali, token o altri dati sensibili. Le normali correzioni di calendario possono invece essere segnalate tramite le issue pubbliche.
